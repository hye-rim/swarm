# 괴물 서바이벌 🧟

사방에서 몰려오는 괴물을 **피해 다니기만** 하면 무기가 알아서 나가는 서바이벌(뱀파이어 서바이버식). 경험치를 모아 **레벨 업**하면 무기와 능력을 골라 강해지고, **8분**을 버티면 나타나는 **대왕**을 쓰러뜨려야 이긴다. 캐릭터·그림·소리는 모두 이 게임에서 새로 그린 것이다. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. 서버 없이 정적 파일만으로 돌아간다(`index.html`).

- **조작**: 폰은 화면을 누르고 끌면 그 자리에 **조이스틱**이 생긴다(기준점이 손가락을 따라와서 방향이 바로 바뀐다). PC 는 방향키·WASD, 레벨 업 카드는 1·2·3 또는 클릭, P 일시정지, M 소리. 공격 버튼은 없다.
- **움직임**: 속도 62px/s 로 일정(대각선도 같다). 화면 가운데에 캐릭터가 있고 세계가 움직이는 끝없는 바닥. 괴물에 닿으면 체력이 줄고 0.45초 동안 안 맞는다. 체력은 천천히 저절로 찬다.
- **무기 5종**(레벨 1~5, 처음엔 마법 화살만 가지고 시작):
  - 🔮 **마법 화살**: 가장 가까운 괴물에게 쏜다. 레벨이 오르면 화살이 2개·3개, 피해와 관통이 늘어난다.
  - 🌀 **회전 칼날**: 몸 둘레를 돈다. 닿은 괴물에게 0.4초마다 피해와 밀치기.
  - ⚡ **번개**: 화면 안의 무작위 괴물에게 친다(번개 1~4번).
  - 🔥 **불꽃 장판**: 괴물이 가까운 곳에 불이 번져 0.3초마다 피해를 준다.
  - 🪓 **도끼**: 높이 던져 올려 떨어지며 괴물을 뚫고 지나간다.
- **능력 5종**(레벨 1~5): 💪 힘(피해 +15%) · 👟 빠른 발(이동 +8%) · 🧲 자석(경험치를 더 멀리서 빨아들임) · ❤️ 튼튼함(최대 체력 +20, 조금 회복) · ⏱️ 재빠름(쉬는 시간 -8%). 모든 무기와 능력이 5레벨이 되면 카드가 **고기(체력 +40)** 로 바뀐다.
- **레벨 업**: 경험치 구슬(파랑 1·초록 2·빨강 5~)을 먹는다. 레벨 업 때마다 게임이 멈추고 카드 세 장 중 하나를 고른다(서로 다른 것으로 뽑힌다).
- **괴물**: 박쥐(빠르고 약함) · 좀비(느림) · 해골 · 오우거(크고 단단함, 1분 뒤부터 점점). 시간이 갈수록 더 자주, 더 단단하게(4분에 체력 2배) 나오고, **2분·4분·6분에 사방에서 한꺼번에** 몰려온다. 너무 멀어진 괴물은 다시 가까이로 보낸다.
- **대왕**: 8분에 나타난다(체력 보통 1000 · 쉬움 700). 4초마다 박쥐를 불러내고, 나온 뒤에는 보통 괴물이 뜸해진다. 쓰러뜨리면 이긴다.
- **난이도**: 쉬움(체력 130, 괴물 체력 ×0.7·수 ×0.7·피해 ×0.75) · 보통(체력 100, ×0.85·×0.9·×0.9). 처음 화면에서 고르고 저장된다(`swDiff`).
- **점수**: 괴물 10(대왕 1000) + 버틴 초 × 5 + 이기면 3000. 최고 점수는 `swBest`(로비 표시용). 튜토리얼(`?tutorial=1`)은 체력이 1 밑으로 안 내려가고 첫 레벨 업이 빨리 오며 기록하지 않는다.
- 화면이 가려지면(탭 전환) 저절로 멈춘다.

규칙은 `logic.js`(화면 없이 Node 로 시험), 화면·입력·소리는 `game.js`. 같은 난수(시드)와 같은 움직임이면 항상 같은 판이다. 시험은 `node --test`(디렉터리): `test/logic.test.js` — 이동 속도, 괴물의 추격·밀어내기·접촉 피해, 무기 다섯 가지 각각(화살 조준과 레벨별 개수·관통, 칼날 회전과 타격 간격, 번개, 불꽃 장판, 도끼), 구슬과 자석, 레벨 업 카드, 5레벨 한계와 능력 효과, 괴물이 나오는 자리·속도·종류·큰 무리, 대왕, 죽음과 승리, **균형 점검**(가만히 있으면 일찍 죽고, 피해 다니는 봇은 훨씬 오래 버티며 쉬움이 더 쉬운지), 결정성과 긴 무작위 실행.

- **균형 참고**(시험용 봇으로 잰 값, 사람과 다를 수 있다): 쉬움에서 피해 다니는 봇은 열 번 중 아홉 번 대왕을 잡고, 보통에서는 열네 번 중 다섯 번 안팎. 가만히 있으면 쉬움은 2~4분, 보통은 1~2분 안에 죽는다.
- **다음에 넣을 만한 것**: 무기 더 많이(방패·부메랑·독), 무기끼리 합쳐지는 진화, 캐릭터 고르기, 상자(보물), 8분 뒤에도 이어서 하는 무한 모드.
